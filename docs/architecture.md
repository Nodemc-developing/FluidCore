# 设计决策

作者：ydxc20091。版本：0.1.0-SNAPSHOT。

## 模块边界

- `api`：稳定候选接口与数据模型，无 CE、Bukkit、Sparrow、NBT、Minecraft 内部类。
- `core`：默认储罐、存储视图、事务转移、注册表及编码实现。
- `paper-ce`：运行插件、CE 桥接、容器与所属线程检查、配置及诊断入口。
- `examples`：独立演示插件与 CE pack，不作为核心强制玩法。

## 资源与数量

流体身份包含标识和不可变组件；数量单独保存，采用非负 `long`。一桶为 1000 mB。空流体使用明确空值，不能把未知流体映射为空。组件内容也必须不可变，数组及其它可变值必须防御性复制。

## 事务

第一次修改参加事务的对象时保存快照。根提交先验证所有对象，再将事务状态标记为提交，最后执行通知；回调失败不能回滚已提交状态。未提交、验证失败或操作异常时恢复快照。嵌套提交并入父事务，父回滚仍能恢复子修改。

对象在事务中按有效所有权锁定。相互独立但同线程的根事务不能交错修改同一参与者。参与者必须在发生修改之前登记快照，不能依赖通用接口反推可回滚能力。

事务只在一个所属执行上下文内使用，不能跨 tick、线程、Folia 区域或异步等待。跨区域请求拒绝，不做非原子的跨区伪事务。持久化是提交后独立过程；不提供跨玩家和区块的崩溃原子落盘。

## 生命周期和热路径

普通储罐无周期任务；处理器按事件唤醒。CE 私有实现不进入公共 API。读取快照后才交后台编码和 I/O；返回时验证版本及重载代次，过期结果不覆盖新数据。有界队列满时拒绝，不在所属线程执行 I/O。

实现保障守恒、线程归属和损坏数据保护。缓存不得跨配置代次或 block entity 生命周期保留 provider。
